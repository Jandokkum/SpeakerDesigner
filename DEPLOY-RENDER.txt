SpeakerDesigner Online 2.5.2 — deployment quick guide

1. Create a GitHub repository named SpeakerDesigner-Online (Private is fine).
2. Upload these project files to the repository root:
   index.html, server.py, requirements.txt, render.yaml, README.txt, DEPLOY-RENDER.txt
3. In Render, choose New -> Blueprint (or New -> Web Service), and connect the GitHub repository.
4. If using Blueprint, Render reads render.yaml. If using Web Service manually:
   Runtime: Python
   Build command: pip install -r requirements.txt
   Start command: python server.py
   Health-check path: /api/health
5. Deploy and wait for the build to complete. Open the Render URL and check:
   - the main page loads
   - /api/health returns JSON with ok:true

Free Render services can sleep after 15 minutes idle; the first request after sleep may take about a minute.
This is still a prototype: review security/rate limits and test external search/PDF import after deployment before sharing publicly.
